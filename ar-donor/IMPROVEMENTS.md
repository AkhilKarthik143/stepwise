# Autonomous Improvement Loop — Charter & Backlog

This file governs the 24/7 multi-agent improvement loop running on this project.
Each iteration reads this file, executes the next item, verifies, logs, commits.

## How one iteration works

1. **Pick** the top unchecked item from the Backlog below (or run a discovery
   workflow to refill it when empty/stale).
2. **Implement** it — one improvement per iteration, scoped and reviewable.
3. **Verify** — ALL gates must pass or the iteration is reverted:
   - `./.venv/Scripts/python.exe -m pytest -q` → 100% pass
   - `cd web && npm run typecheck` → clean
   - `bash web/deploy.sh` → builds + deploys
   - serve check: `/` and `/metrics` return 200 via TestClient
   - `python scripts/test_webrtc_loopback.py` → PASS (when transport touched)
4. **Checkpoint** — `git commit` the verified result (one commit per iteration).
   If gates fail and can't be fixed within the iteration: `git checkout -- .`
   back to the last green commit and log the failure.
5. **Log** the outcome in the Iteration Log below.

## Hard guardrails (never violate)

- NEVER touch `.env`, credentials, or `certs/` — never echo the API key.
- NEVER remove or weaken existing tests to make a gate pass.
- NEVER add a runtime dependency without recording the reason here.
- NEVER refactor the Gemini WS protocol path or aiortc transport without the
  loopback test passing afterward.
- One improvement per iteration. No drive-by changes outside the item's scope.
- The working tree must be CLEAN (committed or reverted) at iteration end.
